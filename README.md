# MiniCriollos - Gestión de Inventario

## Descripción
MiniCriollos es un sistema de gestión de inventario
para consultar productos, administrar existencias,
registrar ventas y generar reportes.

El proyecto se desarrolla para la asignatura
Metodologías de Desarrollo de Sistemas de Información.

## Metodología
Scrum, organizada en cuatro Sprints:

1. Consulta de productos.
2. Gestión de productos.
3. Ventas y alertas.
4. Dashboard y reportes.

## Tecnologías previstas
- React: interfaz de usuario.
- Node.js: microservicios backend.
- PostgreSQL: base de datos.
- Docker: contenedores.
- Git y GitHub: control de versiones.
- GitHub Actions: integración y entrega continua.

## Arquitectura propuesta
El sistema tendrá tres microservicios:

- inventory-service: productos e inventario.
- sales-service: carrito y ventas.
- reports-service: estadísticas y reportes.

## Estado del proyecto
En preparación del entorno de desarrollo.
La implementación de las funcionalidades está pendiente.
